# Approved Software Catalogue (SAMPLE)

> SAMPLE DOCUMENT for demonstration only. Replace with your organisation's catalogue.

**Default deny:** any software that is not listed under "Pre-approved" below is NOT allowed until an
admin approves a software request for it.

## Pre-approved (install the latest supported version, no request needed)
| Software | Category | Notes |
|---|---|---|
| 7-Zip | File archiver | Latest version only; older versions had critical CVEs. |
| Notepad++ | Text editor | Latest version only. Plugins require a request. |
| Adobe Acrobat Reader | PDF reader | Use the Continuous track. Acrobat Pro needs a licence request. |
| Google Chrome | Web browser | Managed by IT policy; auto-update must stay on. |
| Microsoft Edge | Web browser | Managed by IT policy. |
| Zoom Workplace | Video conferencing | Organisation account sign-in only. |
| Microsoft Teams | Collaboration | Standard collaboration tool. |
| Visual Studio Code | Code editor | Extensions from the official marketplace only. |
| Python | Programming language | Supported release cycles only (not end-of-life). |
| VLC media player | Media player | Latest version only. |

## Restricted (request + CISO approval)
| Software | Reason |
|---|---|
| TeamViewer | Remote access tool, frequently abused for fraud and intrusion. |
| AnyDesk | Remote access tool, frequently abused for fraud and intrusion. |
| Dropbox / personal Google Drive client | Personal cloud storage; risk of data leakage. |
| Wireshark | Network capture tool; security or network team roles only. |

## Prohibited
| Software | Reason |
|---|---|
| uTorrent, BitTorrent, qBittorrent | Peer-to-peer file sharing. |
| CCleaner | History of a supply-chain compromise; bundled software. |
| Any cracked or keygen software | Licensing violation and malware risk. |
| Cryptocurrency miners | Resource abuse and malware risk. |
